## Name: fast-api-db

## Description

DB module integration of a PostgreSQL database connection into FastAPI application using SQLAlchemy package.

## Usage

Install `"fast-api-db` into fast-api-server application using poetry.

```bash
poetry add ../packages/fast-api-modules/sqlalchemy
```

## Links
[SQLAlchemy guide for FastAPI](https://www.sqlalchemy.org/)

- sqlalchemy
- fastapi
