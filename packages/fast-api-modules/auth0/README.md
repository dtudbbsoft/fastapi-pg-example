## Name: fast-api-auth0

## Description

Auth0 authorization module for FastAPI.

## Usage

Install `fast-api-auth0` into fast-api-server application using poetry.

```bash
poetry add ../packages/fast-api-modules/auth0
```

## Links

[Auth0 guide for FastAPI](https://auth0.com/blog/build-and-secure-fastapi-server-with-auth0/#Set-Up-an-Auth0-API)

- pyjwt
- fastapi
